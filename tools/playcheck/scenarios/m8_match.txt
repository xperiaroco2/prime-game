# A whole M8 match (GDD §3 "The M8 release", docs/ROADMAP.md M8), lobby to End and back, in two of
# the game's real windows: the release check of #1095. The host sets 0 humans (`setting
# dissidents 0`: aliens only, as M8 plays; the setting's default is 1) and a 3 minute match
# (`setting match_duration 3`, the host's own lobby setting), so the timer's end comes after the
# rest. In the lobby window 2 walks to the mirror and takes its place with E: the colour menu shows
# and frees the pointer (shot; its swatches have no text, so playcheck cannot click one), and E
# again gives the place up and captures it. Then both press Ready. In the round, on the estate's
# clearing (the round's start markers are shuffled, up to about 14 m apart), window 1 faces window
# 2 and waits; window 2 walks into it for 4 s, then swings the bare fist (`use`) 4 times, 0.6 s
# apart (the hit's cooldown is 0.5 s), and steps back. Window 1 asserts the Damaged that only the
# one hit receives. It then walks up the ship's ramp (`to_ship`, ship_engine.txt's route) to the
# console and starts the engine with E; nobody mends the first problem, so the engine blasts and
# window 1, aboard, goes down (KnockedDown); it holds Give up until it is dead (Died), shows the
# dead's room with its respawn time (shot), and returns (Respawned, shot). Both windows then wait
# for the timer: the End screen (shot) says "The aliens lost" in the winner's place (an aliens-only
# match that runs out of time has no winner, #1627), then the lobby again.
# Its shots:
#   mirror_menu          window 2: the mirror's colour menu in the lobby
#   pregame_host         window 1: the role reveal
#   round_start          window 1: the clearing at the round's start, facing window 2
#   fist_hit             window 2: after its last swing (it cannot know whether one landed)
#   console              window 1: at the engine console after E
#   blast                window 1: the engine's blast
#   downed               window 1: knocked down by the blast
#   dead_room            window 1: dead, in the dead's room
#   returned             window 1: back after the respawn
#   end_host, end_guest  the End screen in both windows
#   lobby_again          window 1: the lobby after the End
# The crystal hit is not scripted: a crystal reaches a hand only through the engine's spent-crystal
# problem, which the engine deals at random. With its join, loading and End the run takes about
# 5 minutes: its `run 600` gives it the time (#1713; it said `--seconds 600` before).
